Create a polished, responsive Figma Make prototype for `Victory International`, a premium Thailand Destination Management Company. The prototype should feel like a serious B2B DMC product, not a generic travel-template website.

## Product

Victory International helps travel agencies, corporate/MICE planners, incentive groups, luxury advisors, wedding planners, and group travel buyers design and operate Thailand programs.

The company handles:

- Custom Thailand itineraries.
- Hotels, villas, transfers, guides, restaurants, excursions, and activities.
- MICE, incentives, gala dinners, business events, and group logistics.
- Proposal-ready travel programs reviewed by human DMC specialists.

The main business goal is qualified proposal requests. Do not optimize the prototype around generic trip search.

## Visual System

Style:

- Premium.
- Clean.
- Editorial.
- Thailand-specific.
- Operationally credible.
- Warm but business-focused.

Palette:

- Ivory: `#F7F3EA`
- Charcoal teak: `#182321`
- Deep green: `#173F35`
- Muted jade: `#6E9C87`
- Brass: `#B98B45`
- Warm clay: `#B66B4D`
- Soft sea/sky blue: `#A8D5DD`
- White: `#FFFFFF`
- Text grey: `#5E6863`
- Border: `#D9D7CE`

Typography:

- Editorial serif for large page titles.
- Humanist sans for body, UI, forms, nav, and admin.
- Letter spacing should be 0.
- Do not use viewport-scaled text.
- Do not use decorative script for important UI.

Layout:

- Desktop max content width: 1200-1280px.
- Use a 12-column desktop grid.
- Use responsive structure with flex/grid behavior.
- Cards should be 8px radius or less.
- Use cards only for repeated items, small tools, modals, and admin panels.
- Do not nest cards inside cards.
- Major sections should be full-width bands or unframed layouts.
- Text must fit cleanly in all buttons, chips, tabs, cards, and form fields.

Interaction:

- Primary CTAs should be obvious.
- Tabs should switch content.
- Wizard steps should feel clickable.
- Admin table filters should be visible and believable.
- Add hover/focus-ready states where useful.
